## Projects

### AruniHealth Connect
Medical device integration platform. Bridges bedside ICU ventilators (Mindray SV350) to SIMRS Khanza via HL7/MLLP → Go Bridge → Laravel API. Real-time TTV monitoring, nurse confirmation workflow, critical alert via WhatsApp.  
      
→ [rsamjkt/arunihealth-connect](https://github.com/rsamjkt/arunihealth-connect)

### Arunika TARA
Go service — internal tooling for Arunika infrastructure.  
  
→ [rsamjkt/Arunika-TARA](https://github.com/rsamjkt/Arunika-TARA)

### wago
WhatsApp + Go utility service.  
  
→ [rsamjkt/wago](https://github.com/rsamjkt/wago)

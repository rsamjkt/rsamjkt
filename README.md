### 🩺 What I build

I build the systems that keep a hospital running — **SIMRS, LIS, EMR/RME, finance** — and the integration layer in between. My niche: **bridging clinical lab analyzers ↔ hospital information systems over HL7 v2.x / ASTM E1381/E1394** — the protocols that make an analyzer *speak* to the rest of the hospital.

Mostly a one-person full-stack shop under the **Arunika / AruniHealth** umbrella, shipping real systems used by Indonesian hospitals.

### 🚀 Featured work

**🔬 ATTA LIS** — *Laboratory Information System*
> A Go gateway that speaks **HL7/MLLP & ASTM E1381/E1394** to **85 analyzer models** (Mindray · Sysmex · Roche cobas · Abbott · Beckman · EDAN …), with analyst→doctor validation (two-person rule), Westgard QC, Blood Bank / UTD, and critical-value alerts over WhatsApp.
> `Laravel 12 + Livewire 3` (v2) → **rewriting to** `FastAPI + Next.js + PostgreSQL + Go` (v3).

**🏥 SIMRS Harapan Mulia** — *Hospital Information System*
> A modern rewrite of the hospital's core system — clinical EMR, registration, billing.
> `FastAPI · Next.js 14 · PostgreSQL`

**🦷 [react-odontogram](https://github.com/rsamjkt/react-odontogram)** — *open source*
> A lightweight, fully customizable React component for visualizing a dental odontogram.

**⚙️ Infra & tooling** — [`arunika-wa`](https://github.com/rsamjkt/arunika-wa) (WhatsApp gateway on WAHA) · `Arunika-Tunnel` (nftables port-forwarding with a web UI, single Go binary) · `arunicontrol-web` (fleet monitoring) · `arunihealth-usg-ocr` (Flask OCR for ultrasound biometrics).
